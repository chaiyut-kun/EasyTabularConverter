# Project Description
โปรเจ็คนี้ได้จัดขึ้นจาก pain point ที่รุ่นน้องนักศึกษาวิทยาการคอมพิวเตอร์ได้เล่าถึงโจทย์ที่จำเป็นต้องใช้ข้อมูลตารางในรูปแบบ HTML Table และนำมาเป็น script insert สำหรับการสร้างตารางฐานข้อมูลแบบ SQL จึงได้จุดประกายความสนใจในการแปลงข้อมูลแบบ Tabular Format ขึ้นมา
โดยได้แรงบันดาลใจมาจากเว็บไซต์  https://tableconvert.com/

# Prototype 
ระยะแรกโปรเจ็คนี้จะจัดทำขึ้นเป็นรูปแบบ web mockup เพื่อโชว์รูปแบบของแอปพลิเคชั่น, ฟังก์ชันความสามารถของระบบ
โดยใช้เครื่องมืออย่าง Gemini CLI เป็น AI Agents ช่วยสร้างระบบขึ้นมาเบื้องต้น

# Conclusion
โปรเจ็คนี้จัดทำขึ้นเพื่อนำเสนอในรายวิชา สัมนาทางคอมพิวเตอร์ ในการเรียนในหลักสูตรวิทยาการคอมพิวเตอร์และสารสนเทศ
และมีแนวทางจะสานต่อไปใช้ในวิชา โครงงานคอมพิวเตอร์ในชั้นปีถัดไป
